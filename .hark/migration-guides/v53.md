# Migration guide for v53

v53 of the SDK bumps the API version to `TKTK`. See the API changelog for more information: TKTK

## Use operation-specific address options for V2 requests

Ordinary V2 request address properties that include `Town` now use operation-specific option types instead of `Stripe.AddressJapanOptions`. Update explicitly typed V2 addresses to use the type exposed by the operation. For example:

```csharp
// Before
Stripe.AddressJapanOptions address = new Stripe.AddressJapanOptions
{
    Town = "town",
};

// After
Stripe.V2.Core.AccountUpdateIdentityIndividualAddressOptions address =
    new Stripe.V2.Core.AccountUpdateIdentityIndividualAddressOptions
    {
        Town = "town",
    };
```

V1 addresses and V2 Kana and Kanji script addresses continue to use `Stripe.AddressJapanOptions`.

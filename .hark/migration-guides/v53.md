This version of the SDK uses API version `2026-09-30.endive`. If the format of this API version looks new to you, see our new [API release process](https://stripe.com/blog/introducing-stripes-new-api-release-process).

Please review our API changelog for `2026-09-30.endive` to understand all the breaking changes to the Stripe API, the reasons behind them and potential alternatives.

The Stripe.net SDK specific [changelog for v53](https://github.com/stripe/stripe-dotnet/blob/master/CHANGELOG.md) has the corresponding changes in the SDKs as well as SDK specific breaking changes.

## .NET 6 is no longer supported

.NET 6 is no longer supported. The package now requires .NET 8+.

**Action required**: Upgrade to a supported .NET version before updating to the latest SDK version. For more information, see our [language version support policy](https://docs.stripe.com/sdks/versioning?lang=dotnet#stripe-sdk-language-version-support-policy).

## Use operation-specific address options for V2 requests

V2 request address properties now use operation-specific V2 option types instead of shared V1 types such as `Stripe.AddressOptions` and `Stripe.AddressJapanOptions`. This includes ordinary, shipping, Kana, and Kanji addresses. Update explicitly typed V2 addresses to use the type exposed by the operation. For example:

```csharp
// Before
var options = new Stripe.V2.Core.AccountUpdateOptions
{
    Identity = new AccountUpdateIdentityOptions()
    {
        Individual = new AccountUpdateIdentityIndividualOptions()
        {
            Address = new Stripe.AddressJapanOptions
            {
                Town = "town",
            }
        }
    }
};
var account = client.V2.Core.Accounts.Update(accountId, options);

// After
var options = new Stripe.V2.Core.AccountUpdateOptions
{
    Identity = new AccountUpdateIdentityOptions()
    {
        Individual = new AccountUpdateIdentityIndividualOptions()
        {
            Address = new Stripe.V2.Core.AccountUpdateIdentityIndividualAddressOptions

            {
                Town = "town",
            }
        }
    }
};
var account = client.V2.Core.Accounts.Update(accountId, options);
```

V1 addresses continue to use the shared V1 address option types.

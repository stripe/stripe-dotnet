# Migration guide for v53

v53 of the SDK bumps the API version to `TKTK`. See the API changelog for more information: TKTK

## Use `Stripe.V2.AddressOptions` for V2 request addresses

V2 request address properties that include `Town` now use `Stripe.V2.AddressOptions` instead of the Japan-specific `Stripe.AddressJapanOptions`. Update explicitly typed V2 addresses to use the neutral V2 type:

```csharp
// Before
Stripe.AddressJapanOptions address = new Stripe.AddressJapanOptions
{
    Line1 = "123 Main Street",
    Town = "Brooklyn",
};

// After
Stripe.V2.AddressOptions address = new Stripe.V2.AddressOptions
{
    Line1 = "123 Main Street",
    Town = "Brooklyn",
};
```

V1 Kana and Kanji address properties continue to use `Stripe.AddressJapanOptions`.
